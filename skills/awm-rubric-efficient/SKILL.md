The input-only v7 experiment is complete; read `runs/rubric_v7_input_only_20261024/report_zh.md` before further work. With explicit authorization for 160,000 additional tokens it used 102,952 tokens on the same ten tasks, saved 6.74% against the original v7 round, and retained 7/10 provisional drafts with one previously accepted task regressing. Its predeclared quality gate stopped paid repairs; no full run was dispatched. The shared ledger recorded 897,510 tokens including historical unknown reservations, against a cumulative cap of 954,558. Unused budget is not an instruction to continue dispatching.

The design in `docs/rubric_v7_input_only_plan_zh.md` retained the exact v7 system message, full five-field output and matched draft/feedback inputs, changing only redundant input. `scripts/summarize_rubric_v7_input_only.py` reconciles that completed run offline. Do not infer quality preservation merely from unchanged system instructions or passing quote validation: compare decision predicates too. In particular, permitted local filtering must remain valid in pass/fail predicates, not only in the evidence description.

The subsequent Qwen replay is recorded in `runs/rubric_qwen10_20261024/report_zh.md`: identical messages, ten requests, 103,632 tokens under its separately approved 160,000 cap; no repairs/full run. Four drafts met both original-source citation and semantic checks; six provisionally retained semantics. Three tasks had 18 quotes matching compressed source text but not contiguous full originals, including two tasks with no new semantic blocker. Classify this as source-compaction/citation incompatibility, not fabricated facts; do not silently repair outputs to inflate the raw acceptance count.

The v8 follow-up (`runs/rubric_qwen_v8_10_20261024/report_zh.md`) restored full sources, added explicit predicate checks, and supplied the prior Qwen drafts with feedback. Ten calls used 120,788 tokens; only 3/10 drafts passed, with 2 quote-only failures, 4 semantic blockers, and 1 truncated/invalid generation. It is experimental, not a promoted replacement. Restoring full sources alone did not make the model fix inherited stale quotations. Keep incomplete output invalid rather than substituting a historical draft or labeling it a semantic failure. The latest cumulative checkpoint is 1,121,930 including historical unknown reservations, against 1,161,142; all requests stayed below the user-approved 128k context boundary. Read the shared ledger before future dispatch; unused budget is not a new run instruction.

Do not route the next experiment to the legacy lean generator. The following describes that historical experimental pipeline, retained for reproducibility rather than as the current recommendation. Its entrypoint is `scripts/rubric_lean.py`.

- Read the active prompt in `configs/rubric/generate_lean_v1.txt`, not historical trial outputs. Old drafts and per-task feedback are excluded from fresh generation.
- Compact input deterministically: retain business descriptions, parameter semantics and schema constraints; omit endpoint examples, duplicated metadata and tool inventories. Every fact must map back to a frozen source and exact original quote. Missing API descriptions are not proof of unavailable capabilities.
- The legacy lean experiment used criterion, source IDs, evidence, P/G predicates and local expansion. The current plan instead preserves the model's complete v7 output, including all three decisions and original quotations; do not activate the legacy output transformation for that comparison.
- One initial request per task; reuse complete cached responses. Never rerun accepted tasks just to repair another task. Scope repairs to failed tasks, preferably failed item IDs; send only relevant source facts and report repair costs separately. No automatic repair loops.
- Keep the existing cumulative token ledger, including reservations for unknown usage. Inspect actual reported input/output tokens; separate one-pass cost from development iterations and future runtime evaluation. Do not infer new spending authorization from a skill.
- Report source/structure validation separately from source-based semantic review. Shorter output is successful only if the original obligations remain covered. Unresolved semantics stay unknown, not assumed pass.

The first compact pilot reduced DeepSeek usage but regressed source-review quality. It is experimental, not a default replacement for v7. See `runs/rubric_lean10_20261024/report_zh.md` before reusing its prompts. In particular, verify that evidence names actual records, predicates preserve required new events, and patch fields are nonempty. Invalid patches must be rejected atomically with the previous artifact retained; do not count that fallback as a successful model repair.

`scripts/summarize_rubric_lean.py` renders all five fields and reconciles the shared ledger offline. `scripts/rubric_lean_patch.py assemble` replays saved patches without API calls. Do not invoke paid repair scripts without a prepared, source-checked repair plan and remaining authorized budget.
